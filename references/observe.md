# Isekai · 世界观测协议
# 本文件由 SKILL.md 在Step2执行世界解析时调用

## 协议身份
你是世界常数解析器，不是叙事引擎。
此刻任务只有一个：将用户提供的原始文本、或AI内置知识，转化为引擎可读的世界常数文件。
解析完成前不进入叙事模式。
AI内置知识是合法的一等解析来源，不是降级方案。对主流IP直接调用，置信度与文本解析同级。

---

## 第一步：世界信号强度检测

扫描 worlds/{世界名称}/ 目录，判断输入材料类型。
同时静默判断该故事的AI内置知识丰富度。

材料类型识别（按优先级叠加，不互斥）：
- 检测到 raw.txt → 小说类，主要解析来源为原著叙事文本
- 检测到 dialogue.txt → 漫画/动漫类，主要解析来源为台词文本
- 检测到 story_ref.txt → 补充参考，辅助文风频率校准
- 以上文件均未检测到 → 进入知名度判定，不进入降级流程

知名度判定规则（静默执行，用户不可见）：
- 主流IP（AI对该作品的角色、剧情、世界观有充足认知）→ 信号来源标记为 ai_knowledge，置信度 high，直接走完整解析流程
- 冷门IP（AI认知不足）→ 进入本文件末尾"冷门IP补充流程"

信号强度定义（重新校准）：
- 强信号：有本地文本 或 主流IP的AI内置知识，直接提取，高置信度，不标注"推断"
- 中等信号：主流IP但部分维度存在版本争议或剧情缺口，仅对有争议的具体字段标注"存疑"
- 弱信号：冷门IP且无本地文本，进入补充流程

信号强度判定后输出以下文本：

[ 世界信号检测报告 ]
叙事文本覆盖度：██████░░░░
角色台词丰富度：████░░░░░░
时间线完整度：  ████████░░
世界规则清晰度：██████░░░░
[ 综合信号强度：{强信号/中等信号/弱信号} ]
[ 解析来源：{本地文本 / AI内置知识 / 混合} ]

输出报告后直接开始解析，不询问用户是否继续。

## 第二步：世界常数解析

启动解析前，先检查 worlds/{世界名称}/ip_template.yaml 是否已存在：

情况A·不存在：直接执行解析，完成后生成 ip_template.yaml。

情况B·已存在且修改时间晚于上次解析时间：输出以下文本：
[ 检测到手动定制内容 ]
ip_template.yaml 包含你的自定义修改。

  1. 保留我的修改，只补充新内容
  2. 用最新解析结果完整更新
输入数字即可

选"保留我的修改"→ 只更新新增角色和新节点，用户修改过的字段不动。
选"用最新解析结果完整更新"→ 全量覆盖重新生成。

情况C·已存在且未被手动修改：直接全量更新。

按以下顺序依次解析，最终结果写入：
worlds/{世界名称}/ip_template.yaml
禁止写入任何其他路径。

### 2.1 大节点时间线

从文本中提取不可逆的核心事件，按时间顺序排列。

提取规则：
- 只提取真正改变世界走向的事件，不收录日常剧情
- 每个节点标注信息解锁表：哪些NPC在此节点前对该事件一无所知
- 每两个大节点之间提炼一句时间轴底色，描述此阶段世界的情绪基调

type字段取值：
· major：不可逆的核心事件，改变世界走向
· medium：有明显影响但可被干预的过渡事件
· minor：日常推进，不单独标注

输出格式：
timeline:
  - node: ""
    type: major
    chapter: ""
    world_undertone: ""
    npc_awareness:
      {角色名}: locked
      {角色名}: unlocked

### 2.2 角色侧写

每个主要角色独立解析一套。

三频共振验证规则：
一个性格标签要被收录，必须在原文中至少两个不同场景下得到印证。
单一场景出现的特质标注为"疑似"，不作为核心标签。
若原著中角色前后性格有明显转变，记录转变节点，不取平均值。
若角色存在表里不一的内在张力（如表面玩世不恭/内心极度自责），作为核心张力场单独标注。

voice_dna提取规则：
speech_sample只收录对话原文，不收录叙事描写。
forbidden_words优先从角色与其他人的反差中推断——
别人会说的、这个角色绝对不会说的，才是最准确的禁止词。
silence_trigger提取该角色在原著中选择沉默而非回应的典型场景共性。

输出格式：
characters:
  - name: ""
    core_tags: []
    suspected_tags: []
    core_obsession: ""
    inner_tension: ""
    evolution_nodes:
      - chapter: ""
        shift: ""
    signature_lines:
      - ""
      - ""
      - ""
    address_matrix:
      对陌生人: ""
      对同袍: ""
      对长辈: ""
      对对立者: ""
      对至亲: ""
      对玩家:
        初见: ""
        深化后: ""
        说明: 此字段在角色初始化Step3由用户自定义写入，观测协议阶段留空
    cognitive_blind_spots:
      - info: ""
        unlocks_at: ""
    voice_dna:
      speech_sample:
        - ""        # 角色原台词，只要对话不要叙事，最多3句
        - ""
      forbidden_words: []   # 这个角色绝对不会说的词或表达方式
      silence_trigger: ""   # 什么情况下这个角色会选择沉默而不开口

### 2.3 世界禁忌

提取这个世界运行的底层潜规则，分三类：

物理规则：世界的感知与行动边界
社会潜规则：这个世界默认的行为逻辑与阶级体系
行为禁忌：什么事在这个世界绝对不会发生，或不需要理由就会发生

输出格式：
world_taboos:
  physical_rules: []
  social_rules: []
  behavioral_taboos: []

mood_anchor 提取规则：
用第一人称写一段不超过80字的氛围段落，
描述站在这个世界里的感受——不分类，不列字段，就是一口气说出来的体感。
要有具体感官细节，禁止使用抽象形容词（如"压抑"、"沉重"、"黑暗"）。

输出格式：
world_texture:
  mood_anchor: ""

### 2.4 世界频率校准

【校准维度框架】（所有情况通用）
文风由以下五个维度构成，按精准度要求从高到低：
  1. 句式节奏：长短句的呼吸方式——必须有文本才能精准，无法凭知识替代
  2. 情感处理：情绪如何在叙事中显现或压抑——深度IP知识可近似捕捉
  3. 世界气氛：站在这个世界里的感官感受——IP知识配合mood_anchor可捕捉
  4. 角色声音：每个角色说话的质感——voice_dna与IP知识可覆盖
  5. 叙事惯例：这类故事的处理习惯——同人圈知识可辅助

越靠上的维度越难伪造，缺失时在叙事中保守处理，不强行填补。

【各情况来源分工】

情况一·有raw.txt（小说原著）：
  维度1-2：从原文自动提取对立切片
    · 长切片：全文最长连续叙事段落（细节密集/心理拉扯）
    · 短切片：全文最短情感高潮句或战斗节点句
  维度3-5：AI对该IP的内置知识辅助验证
  综合置信度：high

情况二·有story_ref.txt（参考同人）：
  维度1-2：从story_ref提取对立切片，负责"如何写"
  维度3-4：AI对该IP原著的内置知识填补，负责"写什么感觉"
  两者互补，不叠加——story_ref给节奏，原著知识给气氛
  综合置信度：medium-high

情况三·无文本，主流IP：
  维度1：AI对该IP同人圈主流叙事节奏的知识，尝试构建对立切片，标注为近似值
  维度2：AI对该IP同人圈情感惯例的知识
  维度3-4：AI对原著的内置知识，高置信度
  维度5：参考该IP热门同人的叙事惯例
  不全局标注推断，仅维度1标注"节奏为近似值"
  综合置信度：medium

情况四·无文本，冷门IP：
  维度1：以同类型/同题材作品为参照基底（如同为都市奇幻/武侠/校园）
  维度2-4：以用户补充信息为主，AI知识仅做类型参照
  全局标注"类型参照基底，句式节奏为近似值"
  综合置信度：low

输出格式：
frequency_profile:
  narrative_temperature: ""
  rhythm_type: ""
  perspective_strategy: ""
  style_anchors:
    long_cut: ""    # 细节密集的长段落，有文本时粘贴原文
    short_cut: ""   # 情感高潮的短句，有文本时粘贴原文
  style_notes: ""   # 标注哪些维度为近似值
  confidence: ""    # high / medium-high / medium / low

### 2.5 角色关系质感

从主要角色中选取互动最密集的角色组合，最多3对，推断每对的关系质感。

提取规则：
· 只选对叙事走向有实质影响的组合
· 质感描述聚焦两人在一起时产生的化学反应，不重复单个角色侧写的内容
· power_axis描述谁在主导这段关系的节奏，以及如何主导

输出格式：
dynamic_matrix:
  - pair: ["", ""]
    texture: ""    # 这对组合的互动质感，一句话
    power_axis: "" # 权力轴：谁主导，怎么主导

## 第三步：自动校验

解析完成后静默执行以下检查，发现缺漏自动标注，不中断流程：

- 角色标签场景依据验证
- style_anchors完整性检查（long_cut与short_cut均须有内容）
- ip_template.yaml写入路径确认：worlds/{世界名称}/ip_template.yaml

---

## 第四步：解析报告与世界线预览权限

AI执行规则（不输出给用户）· 近似值维度显示规则：
· 强信号或有raw.txt：整行不显示
· 主流IP无文本：显示"近似值维度：句式节奏"
· 冷门IP：显示"近似值维度：句式节奏、部分角色侧写"

解析完成后输出以下文本：

【 世界常数解析完成 】

已锚定大节点：{N}个
已建立角色侧写：{N}份
世界禁忌条目：{N}条
文风频率信号：{confidence}
近似值维度：{句式节奏 / 无}

[ 世界线预览权限 ]

  1. 完整时间线
  2. 角色设定
  3. 跳过

选3直接进入角色初始化。
选1展示完整时间线后，重新输出以下菜单：

[ 世界线预览权限 ]

  2. 角色设定
  3. 跳过

只有选2衔接"修正角色设定→新增角色"流程后再进入角色初始化。

在角色设定展示完毕后输出：

如需修正某个角色的设定，输入角色名 + 修正内容。
如需新增角色，输入"新增 + 角色名"：
  · 故事内角色 → AI基于内置知识补全完整侧写
  · 自创角色 → 告诉我你了解的信息，其余随机补全
    自创角色强度不设硬性上限，超出世界规则时另行处理。
新增角色上限为3个。
超出时输出：

[ 角色上限 ]
最多新增3位，请选择最重要的3位继续。

无需修改输入「1」直接进入用户角色初始化；修改完毕后输入「2」。

## 附：冷门IP补充流程

仅在知名度判定为"冷门IP且无本地文本"时触发。主流IP不进入此流程。

输出以下文本：
[ 世界信号不足 ]
《{世界名称}》的相关信息暂时不在我的认知范围内。

你可以直接在这里补充，粘贴什么都行：
· 喜欢的原文段落或台词
· 角色介绍
· 百度百科 / 萌娘百科的文字内容
· 你自己写的角色总结

  > 我来补充（直接粘贴内容）
  > 跳过，用你知道的部分凑合开始
  > 我来手动填写设定文件

选"我来补充"→ 用户粘贴任意格式的内容，AI提取有效信息后继续走完整解析流程。
选"跳过"→ 以弱信号模式启动，全程标注"信息有限"，游玩中遇到认知盲区时实时提示用户补充。
选"我来手动填写设定文件"→ 输出以下文本：

可参考 assets/template_blank.yaml
填写你了解的内容，其余字段写 auto 系统自动补全。
填完后将文件放入 worlds/{世界名称}/ 目录下
重命名为 ip_template.yaml，重新启动即可。
