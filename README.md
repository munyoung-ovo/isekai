# isekai/同人世界

---

让你走进别人写好的故事，AI 实时扮演世界和所有角色，二人称叙事推进

---

两种走法

原著向 — 改一件事要付出代价，世界线会往回推，有时候你会输
爽文向 — 这次命运站你这边

---

**部分功能介绍**

**原著向 / 爽文向**
改变命运要付代价，世界线会往回推；或者，这次让命运站你这边

**怀疑度渗透**
怀疑你有预言？怀疑你是某种更强大的存在，还是说你不是来自这里的

**跑团判定**
高风险操作前世界给你一次判定：大成功、部分成功、或失败——失败不中止故事

**蝴蝶效应**
小节点方向一致、因果自洽，命运大节点自动松动，代价降级

**同人文输出**
走完输入「结束时间线」，它把你们的经历写成文，存成文件，手机也能看

---

**安装**

需要先安装 Claude Code

方式一
```
npx skills add munyoung-ovo/isekai
```

方式二（git clone · 可自动更新）
```
git clone https://github.com/munyoung-ovo/isekai.git
cd isekai && bash install.sh
```

更新
```
bash update.sh
```

卸载
```
bash uninstall.sh
```

**怎么开始**

在 `worlds/` 下新建文件夹，以故事名命名
小说放 `raw.txt`，漫画动漫放 `dialogue.txt`
在 Claude Code 里说：载入同人世界 / isekai

**故事太冷门**

打开 `assets/template_blank.yaml`，填你知道的，不知道的写 auto

**走完之后**

输入「结束时间线」
它会把你们之间发生的事写下来，存成文件，手机上也能看
